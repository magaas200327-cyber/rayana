# Сайт-сюрприз ✦

Небольшой многостраничный сайт-поздравление: вступительная заставка → главная страница с видеофоном и
частицами → страница с анимированным письмом → финал.

## Запуск на своём компьютере

Нужен Python 3. В папке проекта выполните:

```bash
py server.py        # Windows (если не сработает: python server.py)
python3 server.py   # macOS / Linux
```

Откройте <http://127.0.0.1:8000>. Не открывайте `index.html` двойным щелчком: видео и переходы
надёжнее работают через `server.py` (он умеет отдавать видео частями).

## Структура

| Файл / папка | Что это |
|---|---|
| `index.html` | главная страница (видеофон, анимация частиц, кнопка) |
| `message.html`, `letter.js` | страница письма: конверт и пошаговое раскрытие |
| `final.html` | финальная страница |
| `style.css` | общие стили |
| `video-sync.js` | плавное продолжение видео при переходе между страницами |
| `intro/` | вступительная заставка «Eye of Creation» |
| `media/dance.mp4` | фоновое видео |
| `server.py` | локальный сервер |

Подробности и настройки — в `README_RU.txt`.
