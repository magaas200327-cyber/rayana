САЙТ-СЮРПРИЗ — V10: вступительная заставка «Eye of Creation» (V7: страница письма)

КАК ЗАПУСТИТЬ НА WINDOWS
1. Распакуй ZIP в новую папку (внутри должны лежать рядом: index.html, style.css, server.py и папка media).
2. Открой эту папку в VS Code (или в проводнике: Shift + правая кнопка -> «Открыть окно PowerShell здесь»).
3. В терминале выполни:   py server.py
   Если не сработало:     python server.py
4. Открой в браузере:     http://127.0.0.1:8000
5. На всякий случай обнови страницу через Ctrl+F5.
Остановить сервер: Ctrl+C в терминале.
Не открывай index.html двойным щелчком (file://) — видео и переходы лучше работают через server.py.

ВСТУПИТЕЛЬНАЯ ЗАСТАВКА «EYE OF CREATION» (V10)
Порядок показа: открытие сайта -> заставка на весь экран -> один полный круг анимации (около минуты) ->
глаз возвращается и плавно гаснет -> открывается прежняя главная страница (её появление, видеофон, частицы,
кнопка и переходы — без изменений). Пока идёт заставка, главная страница полностью скрыта, её видео стоит
на паузе (и заранее подгружается), а частицы ждут конца заставки. Оба экрана одновременно не показываются.

Откуда анимация: в архиве eye-of-creation-main не веб-страница, а программа на Python (numpy + pygame),
которую браузер запустить не может. Поэтому eye_of_creation.py перенесён на JavaScript построчно: те же миры
ГЛАЗ -> СОТВОРЕНИЕ -> БОЛЬШОЙ ВЗРЫВ -> ГАЛАКТИКА -> ЧЁРНАЯ ДЫРА -> ГЛАЗ, те же формулы, тайминги и эффекты
(порталы, поворот камеры, глитч-склейки, звёздное поле, «живые» символы, свечение, 5 цветовых режимов,
CRT-развёртка, HUD). Перенос сверен с оригиналом: исходный Python-движок и JS-версия считают одинаковые кадры
(отличия порядка 0.00001 — округление float32/float64; сверка — в режиме EYE_STYLE: 'original').

ГЛАЗ — карий и женский, по образцу preview.gif и 1_eye.jpg из архива: миндалевидный разрез с приподнятым внешним
уголком, карая радужка, длинные изогнутые ресницы веером к внешнему уголку, нижние ресницы, стрелка, золотисто-бронзовые
тени на веке, складка века, бровь. Он нарисован кодом в той же ASCII-технике (сами картинки на сайт не копировались),
поэтому остаётся чётким при нырке в зрачок; как и в оригинале, глаз открывается, моргает (сам и по клику/касанию),
следит за мышью или пальцем, а зрачок — «портал» в следующий мир (закрытое веко его прикрывает).
Вернуть глаз оригинальной программы (бирюзово-янтарный, без ресниц): в начале intro/eye-of-creation.js
поставить  EYE_STYLE: 'original'.
На телефонах символы мельче (7 px вместо 10), чтобы были видны ресницы; на вертикальном экране глаз чуть крупнее.

Когда показывается: при первом открытии сайта в каждой новой вкладке. При переходах внутри сайта
(«← Назад», «В начало», кнопка «Назад» браузера) и при обновлении страницы после просмотра — сразу главная.
Посмотреть заставку снова:  http://127.0.0.1:8000/index.html?intro        Отключить:  index.html?intro=0

Управление (как в оригинале): мышь или палец — глаз следит, в СОТВОРЕНИИ ведёт руку Бога; клик/касание — моргнуть;
ПРОБЕЛ — пауза; стрелка вправо — следующий мир; вверх/вниз — скорость; + / - — размер символов;
C — цветовой режим; B — свечение; G — CRT-развёртка; H — HUD (по умолчанию скрыт); F1 или ? — справка;
S — скриншот; ESC или Q — завершить заставку и перейти на сайт.

В ЧЁМ БЫЛА ПРИЧИНА ОШИБКИ
В style.css, в правиле .bg-vignette, была пропущена одна закрывающая скобка у linear-gradient(...).
Из-за неё браузер отбрасывал ВЕСЬ остаток файла, включая весь блок «Rebuilt landing screen»:
слои видео / затемнения / Canvas, скрытие кнопки до анимации, замену анимации <body>.
В итоге Canvas лежал в обычном потоке страницы (сдвигал вёрстку на 720px), кнопка измерялась за пределами
экрана (y≈1245 при высоте окна 720), частицы летели мимо, а кнопка никогда не скрывалась.
Дополнительно: анимация <body> pageReveal оставляла transform/filter, из-за чего body становился
контейнером для всех position:fixed (видео считало 200% от высоты body, а не окна).
Также стандартный http.server не поддерживает HTTP Range (Chrome запрашивает видео именно так).

ЧТО МОЖНО НАСТРОИТЬ (index.html, начало скрипта)
RESPECT_REDUCED_MOTION = false  -> анимация играет всегда. true -> её пропускают те, у кого в Windows
                                    выключены анимации («Показывать анимацию в Windows»).
REVEAL_AT (3200 мс)   — когда появляется кнопка;  TRAVEL_MS — длительность полёта частиц;
OUTLINE_PTS / FILL_PTS — число частиц контура и «пыли» внутри кнопки.

СТРАНИЦА ПИСЬМА (message.html) — ВЕРСИЯ V7
Сцена: то же фоновое видео (те же 200% / +6vh / brightness .48 / saturate .78) -> кнопка «Открыть моё письмо»,
которая проявляется из светящихся частиц (тот же алгоритм и тайминги, что на первой странице) -> по нажатию частицы
разлетаются шлейфом -> появляется закрытый конверт с сургучной печатью -> конверт приподнимается и поворачивается,
открывается клапан, лист поднимается, разворачивается, текст проявляется строка за строкой.
После чтения появляются кнопки «Читать ещё раз» (повтор без перезагрузки) и «Остался последний шаг» (на final.html).
